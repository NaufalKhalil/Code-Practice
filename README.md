# Code Practice

Repositori ini adalah tempat penyimpanan (*repository*) pribadi untuk mendokumentasikan proses belajar, latihan kode, dan proyek mini dari berbagai bahasa pemrograman yang saya pelajari. 

Saat ini, fokus utama pembelajaran saya ada pada bahasa **Python**, **Javascript**, **C#**, dan **C++**. Seluruh dokumentasi, penjelasan kode, dan catatan di dalam repositori ini ditulis menggunakan **Bahasa Indonesia**.
